# AuraMod Practice — Minecraft 1.21.8 Fabric

Исходный проект Fabric-мода на Java 21. Внутри есть `KillAuraModule.java`, регистрация клавиши R, настройки Gradle и GitHub Actions для автоматической сборки JAR.

## Возможности

- Нажми **R**, чтобы включить или выключить тренировочный модуль.
- Мод выбирает ближайших враждебных мобов в радиусе 4,2 блока.
- Поворот камеры выполняется плавно.
- Атака проверяет обычный кулдаун и текущую цель прицела.
- Тренировочная версия намеренно работает только в одиночном мире и не атакует игроков на серверах.

## Как получить JAR через GitHub

1. Создай пустой репозиторий на GitHub.
2. Распакуй ZIP и загрузи **содержимое папки проекта** в корень репозитория, включая скрытую папку `.github`.
3. Нажми **Commit changes**.
4. Открой вкладку **Actions** и дождись зелёного статуса у `Build AuraMod`.
5. Открой успешный запуск и скачай артефакт `auramod-jars` внизу страницы. Внутри будет обычный мод JAR и sources JAR.

## Установка мода

Для Minecraft Java Edition **1.21.8** установи Fabric Loader и Fabric API для этой версии. Затем положи `auramod-1.0.0.jar` из артефакта в `%appdata%\.minecraft\mods`.

## Если сборка не запускается

Проект настроен для Java 21 и Gradle 8.12. Проверь журнал запуска во вкладке Actions, чтобы увидеть точную ошибку.
